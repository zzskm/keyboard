# 46es 출력 샘플 — B 단계 스위치 홀·체결 쿠폰

상태: **2026-11-05 판을 내보냈다, 미발주.** 같은 날 재료가 **MJF PA12-HP 나일론(자연 회색)**으로 정해져 보스 탭 자석 포켓을 Ø3 자석용(3.2)으로 바꿨다. 쿠폰은 그대로다(MJF 최소 벽 1.0 점검 통과, 최소 1.5). 2026-11-06에 재료·색이 바뀌어, 쿠폰은 plate와 같은 **MJF PA12S-HP 검정**, 커버를 대신하는 보스 탭은 커버와 같은 **8001 레진 투명**으로 뽑는다. 쿠폰과 보스 탭은 파일 2개로 따로 [`../print_v4/order1/`](../print_v4/order1/)에 있다(`46es_v4_sw_hole_coupon`, `46es_v4_boss_tab`, 각 STL + STEP). STL은 아래 출력 방향으로 돌려 두었다. 이 폴더에 있던 이전 판(2026-11-04, 145.35 × 50.1) STL/STEP은 지웠다. 주문 1의 시험물이며 46es 부품이 아니다.

## 2026-11-05 개정 이유

1. **plate 3층 구조의 출력 조건을 재현하지 못했다.** plate는 윗면을 바닥에 놓고 출력하므로 14.0 홀 층(1.5)이 위층 16.5 개구 위에 쌓이고, 홀 네 변이 1.25씩 허공에 뜬다(처지면 플랜지가 앉는 면이 두꺼워져 걸쇠가 안 걸릴 수 있다). 이전 행 B는 홀 층을 바닥에 바로 출력해서 이 조건이 없었다 → **행 C** 추가.
2. plate·스탠드오프 나사는 M3인데 M2 구멍만 있었다 → **M3 구멍** 추가.
3. 커버 고정(보스 → 카운터보어, 자석 → 강철 나사머리)을 시험할 곳이 없었다 → **카운터보어 3종 + 보스 탭** 추가(`model/README.md`의 "B단계 쿠폰에 보스/Ø6 구멍 쌍 추가"를 이행).
4. 프레임 육각 포켓 → **육각 포켓 4종** 추가.

## 보스 탭 형상 (`BOSS_TAB_SAMPLE`, 따로 출력)

30 × 30 × 10 블록. 커버 밑면을 흉내 낸 면(Z 10) 가운데에 보스 Ø5.8 × 1.5, 보스 끝에서 자석 포켓 Ø3.2 × 깊이 2.1(설계와 같음). 같은 면에 보스 없는 자석 포켓 Ø3.2 / 3.3 / 3.4 × 2.1 (x 7 / 15 / 23). 2026-11-05 MJF 전환 전에는 Ø4 자석용 4.2 / 4.3 / 4.4였다. 모델 안에서는 쿠폰 +Y 변에서 10 떨어진 곳(y 84.15 ~ 114.15)에 있다.

- 보스 Ø5.8 + 카운터보어 6.0 / 6.2 / 6.4 → 반경 여유 0.1 / 0.2 / 0.3. 결과로 정한 여유를 설계 식 `TBD_cover_boss_D = TBD_so_head_D − 2·TBD_cover_boss_clr`에 넣는다(설계 보스는 5.4, 여유 0.3).
- 보스 벽(보스 바깥 ↔ 자석 포켓): 탭 1.3, **설계(5.4 − 3.2)/2 = 1.1**. MJF 최소 벽 1.0 이상이다. Ø4 자석이면 설계 0.6이라 자석을 Ø3으로 바꿨다.
- 재료: **8001 레진 투명**(커버와 같음, 2026-11-06). 투명 레진 보스가 검정 MJF 카운터보어(B 쿠폰)에 들어가는 조합이 실제 조립과 같다. 레진 권장 벽 0.8 이상이고, 공차는 ±0.2(100 mm 이내)다. 커버의 투명도, 기포, 받침 자국, 자석이 비쳐 보이는 모습도 이 탭으로 본다. 자석은 투명 2액형 에폭시로 붙인다(순간접착제는 투명 레진을 하얗게 흐린다).

## 출력·시험 절차

1. 쿠폰과 보스 탭은 **파일 2개로 따로** 내보냈다(한 파일에 떨어진 바디 2개를 넣으면 업체가 부품 1개로 받을 수 있다). 2026-11-05 완료.
2. 출력 방향(FDM용으로 정한 것. MJF는 서포트가 없어 업체 배치에 맡겨도 된다. 요청할 수 있으면 쿠폰은 판이 바닥과 나란하게):
   - 쿠폰: **홀 면(Z 10)을 베드에.** 행 C는 이 방향에서 plate와 같은 조건(홀 층 1.25 돌출)이 된다. 카운터보어 바닥(나사머리가 앉는 면)도 plate처럼 돌출로 출력된다. 육각 포켓은 위로 열린다(프레임과 같음).
   - 보스 탭: **Z 0 면을 베드에, 보스가 위로**(커버를 윗면 아래로 출력하는 것과 같음).
3. 스위치(Gateron Milky Yellow)를 행 A·B·C 각 홀에 끼워 기록: 삽입력(헐거움/적당/억지), 걸쇠가 걸리는지, 키캡 뽑을 때 스위치가 딸려 나오는지, 흔들림. **행 C는 플랜지가 홀 층에 평평하게 앉는지, 홀 가장자리 처짐을 함께 본다.** 행 B와 C의 차이가 크면 plate 방식을 다시 정한다(upper plate 2T를 별도 부품으로 나누기, 서포트 등).
4. M2·M3 구멍에 나사를 넣어 통과/자가 탭 여부 기록.
5. 카운터보어 3개 각각:
   1. 탄소강 M3 버튼헤드 나사(M3 × 10~12 + 너트)를 넣어 머리가 들어가 바닥에 앉는지.
   2. 나사를 뺀 상태에서 보스 탭 보스를 꽂아 끼움(헐거움/적당/억지)과 흔들림.
   3. 보스 포켓에 Ø3 × 2 자석을 접착하고 나사를 넣은 상태에서 다시 꽂아, 뒤집어도 붙어 있는지·손으로 떼는 힘.
6. 탭 평면 포켓 3개에 Ø3 자석이 들어가는지(3.2 / 3.3 / 3.4) → `TBD_magnet_clr`. 보스 벽 1.3이 깨지거나 비었는지.
7. 육각 포켓 4개에 기존 육각 스탠드오프(M13)를 넣어 들어가는지, 돌려도 안 도는지. 스탠드오프 맞변도 함께 잰다. 프레임의 SO1·SO2·SO4·SO5 자리는 이 맞변 폭 그대로 X 방향 장공이 되므로(2026-11-05), 스탠드오프가 **손으로 밀어 미끄러지면서 돌지는 않는** 포켓을 고른다 → `TBD_so_pocket_clr`.
8. 홀·구멍 실측(캘리퍼 내경조)으로 설계값 대비 편차를 구해 `measurements.csv` M18에 적고 위 매개변수를 정한다.
9. 쿠폰 외곽 145.35 × 74.15와 두께 10을 실측해 축척 오차율(%)을 M18에 적는다. plate 외곽 틈 `TBD_plate_gap`(지금 0.8)을 이 값으로 정한다: 틈 ≥ 오차율 × 143(plate 반폭) + 조립 위치 여유 0.5. 예: +0.2%면 0.29 + 0.5 = 0.79(`../README.md` "plate 보호" 절).

## 재현

`46es_sw_hole_sample.sc`를 SolidCraft MCP 폴더에 복사해 `open`. 이전 판(피처 41개) 위에 2026-11-05에 쌓은 순서: `SMP_rowD`·`SMP_upper` 추가 → `SMP_W` 식 변경 → `SCREW_0…3` 위치 `timeline.edit` → 행 C `HOLE_C*`·`UPPER_C*`·`RELIEF_C*` 21개(`solid.box cut`) → `M3_HOLE_*` 4 → `CB_*` 3 + `CB_HOLE_*` 3 → `SK_HEX_POCKETS`(XY, `sketch.polygon.circumscribed` 4개, 중심 치수 + 한 변 수평) + `HEX_POCKETS` 컷 + `HEX_HOLE_*` 4 → `TAB_BASE`(새 바디) + `TAB_BOSS` join + `TAB_BOSS_MAGNET`·`TAB_MAG_*` 컷.
