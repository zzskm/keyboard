# v5 현행 제작 세트

**주문 1 시험 → 통과 후 주문 2 본 출력.** 두 주문의 STL/STEP은 모두 이 폴더에 있다. CAD·실물 검증 완료나 발주 완료를 뜻하지 않는다. [설계](../../docs/design.md) · [열린 확인 항목](../../docs/validation.md)

시험 출력물은 이전 경로 `print_v4/order1`에서 내용 변경 없이 옮겨 `46es_v5_`로 이름을 통일했다. v5에서 사용하는 동일 부품이다. STEP 헤더의 이전 이름은 형상이나 제작 버전을 선택하는 기준이 아니다. 주문 1 CAD 기준은 현행 v5와 샘플 모델이며 해시는 [시험 출력 기록](../../inspection/data/seam-v5-trial-print-set.json)에 있다.

## 재료·주문 메모

| 부품 | 선택 |
|---|---|
| plate·mount·spine·브래킷·게이트·B 쿠폰·이음 쿠폰 | MJF PA12S-HP 검정 |
| 커버 3조각·보스 탭 | 8001 레진 투명(Transparent) |

위 재료는 기존 설계에서 채택한 조건이다. 기록된 기준은 MJF 벽 1.0 mm, 레진 벽 0.8 mm이며, 실제 업체 수락 조건은 견적 때 확인한다. [8001 자료](https://jlc3dp.com/help/article/photosensitive-8001-resin).

업체에는 STL을 올린다. STL은 베드 면 Z=0의 출력 참고 방향이며 STEP은 조립 좌표다. MJF·레진의 배치는 업체가 정한다. 투명 커버의 턱 윗면과 바닥 윗면은 모두 보이는 면이다. 주문 메모: "Top face (flat side without bosses) is cosmetic. Please put supports on the boss side only."

커버 최소 벽 약 1.098은 보스 둘레이며 다리 자석 포켓 위 살은 1.3이다. 좁은 베젤의 강도·휨은 본 출력 후 확인한다. 스캔의 짧은 모서리 광선 값과 실제 벽 두께를 구분한다. 검토 결과는 [본 출력 벽 검사](../../inspection/data/seam-v5-mjf-thin-wall.json), [시험 출력 벽 검사](../../inspection/data/seam-v5-trial-thin-wall.json)를 따른다.

자석 총수는 10개다(보스 6 + 다리 4). 시험·예비분은 별도다. 보유 r2 지지대(길이 5, 맞변 4.33–4.5)와 위 설계용 지지대(길이 6, AF5)는 다르므로 무조건 재사용하지 않는다. 위쪽 M3 나사는 자석이 붙는지 실제로 확인한다. 자석은 투명 2액형 에폭시로 붙이며 투명 커버에 순간접착제 백화가 생기지 않게 한다.

## 시험과 조립

1. [B 쿠폰·보스 시험](../samples/README.md): 스위치 끼움, 카운터보어, 자석 포켓·흡착력, 육각 포켓과 출력 치수 편차를 기록한다.
2. 이음 쿠폰을 위에서 맞추고 R 아래 너트 포켓에 너트를 넣어 M2×5로 조인다. 단차·흔들림·삐걱임을 확인한다. 빡빡하면 tab 옆면을 조금 다듬고, 헐거우면 본 조립에서 접착 필요 여부를 판단한다.
3. mount 4개를 PSD60에 장착한다. 장공 내 체결과 지지대 포켓을 확인한다.
4. 결과를 현행 v5 생성 규칙과 샘플에 반영하고 재출력·검증 후 주문 2를 진행한다.
5. 본 plate L/R·spine·브래킷을 가조립하고 스위치를 꽂아 중앙 아래쪽 키를 누른다. 이음 보강이 필요하면 배선 전에 결정한다. 배선이 이음을 건너면 반쪽을 벌리기 어렵다.

앞 이음의 현재 구조는 [설계 기준](../../docs/design.md)에 있다. 조립 단계는 [가이드](https://zzskm.github.io/keyboard-46es/)를 따른다.
