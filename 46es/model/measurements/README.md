# PSD60 현물 측정 기록

## 2026-11-04

`2026-11-04T111846Z.json`은 사용자가 측정 도우미에서 내보내 전달한 입력 기록이다.
9개 항목의 입력 필드와 7개 `params` 후보를 보존했다. 측정일은 한국 날짜 2026-11-04다.

**사용자 결정:** 전반적인 실측 정확도가 낮아 기존 STL 기반값을 우선한다.
단, 후속 확인에서 **H 지지대 측정은 신뢰 가능**하다고 지정했다. M08의 입력된
6개 위치값, M05의 H01 높이 5.5 mm, M10의 H01 외경 5 mm는 현물 근거로 사용한다.
나머지 실측은 대략적인 참고 기록이다. JSON `params` 전체를 일괄 채택하지 않는다.
실측 후보를 `parameters.csv`와 `.sc`에 일괄 대입하지 않는다. 조립 여유 설계 변경은 별도로 반영한다. 기존 모델은 Wilmore STL 기반
내측 치수와 GH60 후보 체결 좌표를 함께 사용한다. 둘 다 PSD60 실측 확정값은 아니다.

- M01·M02: 각 1곳 측정. 전체 최솟값으로 확정할 수 없다.
- M05: 지지대 높이는 H01 한 곳. 6곳 평균으로 확정할 수 없다.
- M08: 입력된 좌표 성분은 신뢰 가능한 현물 기준. 내벽 기준 거리이므로 GH60 PCB 원점 좌표에 직접 대입하지 않는다. 미측정 성분은 기존 후보값 유지.
- M10: H01 외경만 입력. 회피 구멍은 시험 조립으로 확인한다.
- M13: 스테인리스라는 재질 기록만으로 자석 흡착 여부를 확정하지 않는다.
- M14: 배선 돌출 약 8 mm는 CAD의 plate 아래 공간 5 mm와 비교가 필요하다.
  프레임과 배선이 같은 XY에서 겹치는지 확인한 뒤 높이를 정한다.

브라우저 자동 저장값은 이 파일 저장으로 바뀌지 않는다. JSON은 측정 도우미에서
다시 가져올 수 있다. 최종 출력 치수 확정 전 시험 지그·쿠폰으로 적합성을 확인한다.

## 다음 설계 작업의 범위

사용자는 r2 조립품을 이미 사용하고 있으며 외곽은 코너 R 조정 외에는 잘 맞는다고 확인했다.
전체 체결 지그보다 r2 형상을 유지하면서 지지대 위치 및 Cover–Plate–Mount 체결 구조를
수정하는 작업을 우선한다. M08의 측정 위치를 반영할 때 내벽 기준과 GH60 기준을 구분한다.
M03 코너 R은 아직 미측정이다. 체결 구조의 구체적인 문제는 추가 확인이 필요하다.

## 측정 정밀도에 대한 최종 방침

사용 도구는 150 mm 캘리퍼이며, 사용자는 설계에 쓸 만큼 신뢰성 있게 재기 어렵다고
설명했다. H 측정은 다른 실측보다 신뢰 가능한 참고지만 소수점 단위 확정치로 간주하지
않는다. 150 mm라는 측정 범위를 1 mm 눈금 또는 특정 정확도 사양으로 해석하지 않는다.
마운트 구멍 중심은 기존 GH60 후보 좌표를 유지하고, 입력된 H 성분과의 차이는 장공
조정 방향을 정하는 데 사용한다. M08의 미입력 6개 좌표 성분은 계속 미측정 상태다.
