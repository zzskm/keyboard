# PSD60 현물 측정 기록

## 2026-11-04 (`2026-11-04T111846Z.json`)

사용자 내보낸 원본(9개 입력, 7개 `params` 후보). **전반 실측 정확도 낮음 → 기존 STL 기반값 우선. JSON `params` 일괄 채택/대입 금지.**

**예외(신뢰 가능한 H 기준, 소수점 확정치 아님):** M08 입력 6개 위치값, M05 H01 높이 5.5 mm, M10 H01 외경 5 mm. 나머지는 참고.

- M01·M02: 1곳 측정 → 전체 최솟값 불가.
- M05: H01만 → 6곳 평균 불가.
- M08: 내벽 기준 거리(=GH60 PCB 원점 직접 대입 불가), 미측정 축은 후보 유지. 구멍 중심은 GH60 후보 유지, 장공 방향 판단에 사용.
- M10: H01 외경만, 회피 구멍은 시험 조립.
- M13: 재질만으로 자석 흡착 확정 불가.
- M14: 배선 ~8 mm vs plate 아래 5 mm, XY 겹침 확인 후 높이 결정.

JSON은 관찰 기록(브라우저 자동저장 아님). 최종 치수는 시험 지그/쿠폰으로 확인.
