## 검증 결과

- **107바디·395피처·58스케치 모두 dof0·오류0·dirty=false**. 경고는 원본 HOUSING_POSTS_CAND1개만 남았다. 중앙 mask의 초기 미세 이동 경고는 support mask에 여유를 주어 해소했다.
- Mount6개와 전체 출력11개 모두 native kernel shell1/closed=true. 검토 STL11개 모두 연결 성분1·비정상 경계 모서리0. CAD 대비 STL 부피 최대 차0.0302%, bbox 차0.05mm 이내. 일반 self-intersection 전체 증명은 아니다.
- 원본 SK22/SK24/SK25/SK34 저장 입력 동일. v1과 공통으로 남은 **101바디의 exact BRep가 전부 동일**하다. Plate 외곽285.781×95.334,46키 XY/각도·높이, cover 자석, 별도 controller bracket/gate, spine 모두 유지했다.
- 107바디 전체 간섭의 시간 제한49쌍을 하드웨어·커버·게이트·M2 묶음과 clearance로 마쳤다. USB 수정 후 해당 어댑터를 나머지106바디와 다시 비교했다. 최종 미평가 쌍0, 의도하지 않은 출력 부품 중첩0이다.

## 조립과 국부 시험

1. 어댑터별로 M3 지지대를 미리 고정한다. 케이스 나사는6곳을 각각 가볍게 체결한다.
2. Plate를 임시로 얹어 각 어댑터의 방향과 장공 위치를 맞춘다. 공구 접근이 막히면 plate를 다시 들어낸 뒤 케이스 나사를 조인다. 전체 케이스 jig는 요구하지 않는다.
3. 케이스 나사 조임 중 어댑터가 돌아가지 않았는지 확인하고 plate를 장착한다. 각 어댑터의 단일 케이스 나사는 조이기 전 회전을 허용한다. 조인 후의 마찰 고정·반복 탈착 유지력은 실물 시험 대상이다.
4. 중앙 shim은 무하중에서 억지로 휘지 않도록 맞춘다. 컨트롤러 게이트는 이전처럼 plate 모듈을 꺼낸 후 아래에서 접근한다.

국부 시험 우선순위는 긴 H03–SO6 어댑터의 굽힘/층간 파손, H01–SO2와 실제 USB·케이블 여유, H02 받침/shim과 plate 중앙 처짐이다. H05 조정 끝의 잔여 살과 각 M3 포켓·나사 길이도 확인한다. v1 시험안의 mount lap/USB U 연결 시험은 v2에는 적용하지 않는다. 스위치·cover 쿠폰 계획은 유지한다.

## 미확정 사항

둘레 끼움과 큰 프레임의 제약은 줄었지만 실제 조립 성공률·강성이 검증된 것은 아니다. 전체 강성은 기존 plate와 spine에 더 의존한다. FDM 재료·층방향·장기 creep·하중/반복 탈착 시험은 미완료이며 특히69.8mm 앞쪽 어댑터를 먼저 시험한다.

실제 케이스 나사 규격/유효 깊이, PCB/USB 변형, 배선·다이오드·납땜, 키캡 스트로크는 여전히 미확정이다. M1.6×14를 케이스 나사로 지정하지 않았다. 키 높이를 자동으로 올리지 않았다. JLC3DP 우선 검토·소재 미정, 최종 제작 승인/발주 없음.

새 web/mask 스케치14개는 현재 후보 좌표를 고정한 형상이다. CSV185개는 기존 사용자 파라미터이며 새 고정 web 좌표 전체를 구동하는 CSV가 아니다. 케이스/SO 기준 좌표를 바꾸면 새 mask·web도 함께 수정하고 재검증한다. 장공 자체의 기존 조정 범위는 보존했다.
