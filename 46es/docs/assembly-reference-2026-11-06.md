# PSD60·MX·OEM 조립 검토 모델 — 2026-11-06

[조립 검토 CAD](../model/46es_assembly_review.sc)는 기존 v4 출력 부품을 복사하고 참고 케이스·스위치·키캡을 갱신한 모델이다. 출력용 원본은 [46es_mount_seam_v4.sc](../model/46es_mount_seam_v4.sc)이며 주문 STL/STEP은 이번에 수정하지 않았다. 가이드는 조립 검토 CAD를 사용한다.

[v5 문서](v5-cover-magnet-margin-2026-11-06.md)를 본다. 이 문서의 수치는 v4 검토 모델 기준이다.

## 케이스 치수의 근거

원래 가이드의 하우징은 PSD60이 아닌 Wilmore 대용 모델이었다. 부분 실측을 케이스 전용 `REF_PSD_*` 매개변수에 반영했다. 출력 부품을 구동하는 `TBD_*`, GH60 체결 후보 `CAND_H*`, 원점 오프셋은 그대로 보존했다.

| 항목 | 이전 가이드 | 갱신 검토 모델 | 근거·한계 |
|---|---:|---:|---|
| 내측 폭 | 286.381 | 약 286 mm | M01 앞·지지대 높이 한 곳 |
| 내측 깊이 | 95.934 | 약 96 mm | M02 좌·지지대 높이 한 곳 |
| 내부 바닥→지지대 상면 | 6.196 | 5.5 mm | M05 H01 한 곳. 다른 5곳은 같은 높이로 가정 |
| 지지대→앞 테두리 | 12.173 | 약 14 mm | M05 부분 실측 |
| 지지대→뒤 테두리 | 11.891 | 약 14 mm | M05 부분 실측 |
| 외곽 폭×깊이 | 312.904×117.713 | 320×115 mm | M04 문서 공칭값. 실측 아님 |
| 기둥 외경 | 5 | 5 mm | M10 H01. 다른 곳은 같은 외경으로 가정 |

[실측 원본](../model/measurements/2026-11-04T111846Z.json)의 M08에서 H01 X=26, H02 Y=49, H03 Y=11, H04 Y=68, H05 X=4, H06 Y=39 mm를 읽어 **해당 축만** 케이스 기둥에 적용했다. 내벽 기준 거리이므로 기존 GH60 원점 오프셋 X=0.693, Y=0.667 mm를 빼서 변환한다. 미측정 축은 GH60 후보를 유지한다. 원점 오프셋 자체도 미측정이므로 정밀 좌표로 확정한 것이 아니다. 출력 mount는 GH60 장공 설계를 유지한다.

외곽의 좌우·앞뒤 여백은 대칭으로 가정했다. 코너 R, 외벽 구배, 앞 모따기, 바닥 외면의 경사와 두께, USB 개구부의 정확한 위치·규격은 실측이 없다. 일부는 기존 Wilmore 대용값을 유지했다. 이 모델을 PSD60 전체 실측 CAD로 취급하지 않는다. 기존 측정 CSV의 신뢰도·채택 이력은 덮어쓰지 않았다.

내측 폭을 정확히 286으로 놓고 이전 원점 오프셋을 유지하면, plate·커버 오른쪽 끝 X=285.388이 내벽 X=285.307을 약 0.081 mm 넘는다. 폭·원점이 대략값이므로 이 수치만으로 출력 부품을 줄이지 않았다. 전체 plate 폭은 약 285.781 mm이며, 케이스 실물에서 중심 맞춤과 벽 접촉을 확인해야 한다. 높이 비교와 끼움 확정은 별개다.

## 커버가 올라오는 높이

**사용자 현물 확인(2026-11-06): r2 커버는 케이스 테두리 위로 최소 3 mm 돌출되며, 5 mm 아래층과 2 mm 위층 모두 테두리 위에 보인다.** 같은 날 재확인: **체결 상태에서 가장 낮은 곳이 3 mm, 즉 확정 최소 3 mm**다. 아래의 약 1 mm는 구조가 달라진 v4 검토 CAD의 계산값이며 r2 실물 재현 또는 실물 검증 결과가 아니다. r2를 재현하려면 두 커버 층과 하부 적층의 높이를 함께 대조해야 한다. 이 관찰만으로 케이스 테두리 실측값을 변경하거나 v4 전체를 2 mm 올리지는 않는다.

조립 좌표의 Z=0은 케이스 지지대 상면이다. 케이스의 타이핑 경사는 정규화된 좌표이므로 책상면 기준 앞·뒤 외형 높이와 직접 비교하지 않는다.

| 기준면 | Z (mm) |
|---|---:|
| 케이스 내부 바닥 | −5.5 |
| 케이스 지지대 상면 | 0 |
| mount 기준 상면 | 3 |
| plate 상면 | 13 |
| 케이스 테두리 상단 | 14 |
| 커버 평판 밑면 / 윗면 | 13 / 15 |

이전 모델에서는 커버 윗면이 앞 2.827 / 뒤 3.109 mm 올라왔다. 갱신 모델에서는 **앞뒤 약 1 mm** 올라온다. 커버 밑면은 테두리보다 약 1 mm 낮다. 커버의 2 mm 평판 두께와 현재 적층에서 나온 결과이며, 커버를 억지로 내리거나 plate·스탠드오프 높이를 변경하지 않았다. 가이드의 `앞 높이` 시점과 분해 슬라이더 0에서 확인할 수 있다. 부분 실측 오차와 실제 테두리 형상이 미확정이므로 현물의 정확한 돌출량은 아직 확정할 수 없다.

## 키스위치·키캡 참고 모델

- 스위치: gcb의 [Thingiverse 421524, Cherry MX switch reference](https://www.thingiverse.com/thing:421524), 저자 공개 [switch_mx.scad](https://gitlab.com/gcb/3dump/-/blob/master/keyboards/cherry/switch_mx.scad)를 참고했다. 하부 하우징·플랜지, 테이퍼 상부 하우징, 노란 십자 스템, 중앙/좌우 플라스틱 가이드와 금속 접점 2개를 구분한 5핀 형상이다. Gateron KS-3 Milky Yellow Pro의 정밀 도면은 아니며 세부 걸쇠·가동 구조는 생략했다.
- 키캡: rsheldiii의 [Thingiverse 468651](https://www.thingiverse.com/thing:468651)과 동일 저자의 후속 라이브러리 [KeyV2](https://github.com/rsheldiii/KeyV2), 특히 [OEM 프로파일 설정](https://github.com/rsheldiii/KeyV2/blob/master/src/key_profiles/oem.scad)을 참고했다. 사용자 확인에 따라 OEM 형상으로 만들었다. Thingiverse 본문은 접근 제한(403)이 있어 저자의 공개 소스를 확인했다.
- 외부 STL/소스 파일을 재배포하지 않고 별도 생성기로 단순화된 검토용 솔리드를 작성했다. 사용자 요청으로 키캡 곡면·오목 면·내부 소켓을 생략하고 평평한 윗면의 단순 솔리드로 만들었다. OEM 행별 높이·윗면 경사·뒤쪽 오프셋과 키별 폭만 표현한다. KeyV2의 OEM 참고 수치는 하단 18.05, 상단 폭 감소 5.8/깊이 감소 4, 뒤쪽 오프셋 1.75 mm이다.
- 46개 중심·회전은 r2 배치를 유지한다. 맨 아랫줄 폭은 사용자 확인값 1.25u·1u·2.25u·2u·1u·1u이며 다른 키는 기존 폭 표를 따른다. 문자 3행은 OEM R2/R3/R4, 아래 엄지·하단 화살표는 R5, PgUp/PgDn은 R1/R2로 가정했다. 키캡 제조사·정확한 행 배정·스태빌라이저와 눌림 간섭은 현물 확인이 필요하다.
- 스위치 착좌 기준은 plate 최상면 Z=13이 아니라 2 mm 상부 개구 아래의 걸쇠층 상면 Z=11이다. 스템 상단은 Z=20.3, 키캡 하단은 Z=15.2 mm로 배치했다. 키캡 외형만으로 실제 스위치 스트로크 간섭이 검증된 것은 아니다.

## 재생성과 검증

```powershell
python tools/build_assembly_reference.py
python inspection/scripts/verify_assembly_reference.py
python guide/build_guide.py
python -m http.server 8766 --bind 127.0.0.1 --directory guide/out
# http://127.0.0.1:8766/#interactive
```

`model/assembly_reference.json`은 원본 CAD·실측 JSON·생성기·검토 CAD의 해시와 키별 OEM 행 배정을 기록한다. 원본 또는 생성기가 바뀌었는데 검토 모델이 그대로이면 가이드 빌드가 중단되어 재생성을 안내한다. 검증은 출력 부품의 원본/검토 모델 BRep 비교, 케이스 기준 치수, 46개 스위치·46개 키캡 수량·배치를 확인한다.
