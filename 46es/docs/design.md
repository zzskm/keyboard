# 현행 설계 — v5

PSD60 Defender에 넣는 46키 non-split hand-wired 키보드다. 아크릴 r2의 키 중심·회전·외곽을 유지한다. plate는 좌우 두 조각이며 mount 4개, spine, 분리형 Pro Micro 브래킷·게이트, 자석 커버 3조각을 조합한다. 스태빌라이저는 사용하지 않는다.

## 기준과 변경 경로

- 현행 CAD: [46es_mount_seam_v5.sc](../model/46es_mount_seam_v5.sc). `tools/build_seam_v5.py`가 [고정 v4 입력](../model/baselines/seam_v4.sc)에서 생성한다.
- 매개변수 CSV는 CAD에서 내보낸 결과다. 생성기 수정 → CAD 재생성 → 검토·제작 출력 → 검증 → 가이드 순서로 갱신한다.
- [조립 검토 CAD](../model/46es_assembly_review_v5.sc)는 부분 실측 케이스와 단순화된 MX·OEM 참고 형상을 추가한 파생 모델이다. 실물 적합성 보증이나 주문용 파일이 아니다.
- 기준 좌표: GH60 PCB 앞·왼쪽 원점, X 오른쪽, Y 뒤쪽, Z=0 케이스 지지대 상면. 타이핑 경사를 정규화했으므로 책상면 기준 높이와 직접 비교하지 않는다.

## 현행 치수

|---|---|
| plate 상면 | Z 13 mm |
| 스위치 상부 개구 / 걸쇠 홀 층 / 아래 릴리프 | 1.7 / 1.5 / 1.8 mm |
| 스위치 착좌 | Z 11.3 mm. 14.0 mm 홀은 시험 출발값 |
| 커버 윗면 / 본체 두께 | 평면 Z 19.0 mm / 6.0 mm |
| mount–plate 접촉면 | Z 8.0 mm, 둥근 일체형 받침 7곳(총 약 355 mm²) |
| 커버 다리 자석 포켓 위 살 | 3.9 mm |
| 커버 창과 참고 키캡 간격 | 1.0 mm. 쉴 때·4 mm 눌림 모두 |
| 참고 키캡 밑면 | 착좌 +6.0 = Z 17.3 mm. 실측 확정값 아님 |
| 참고 키캡 4 mm 눌림 후 plate 간격 | 0.3 mm |
| 케이스 테두리 | Z 14 mm 대략 실측. 커버 윗면 +5.0 |
| plate·커버 전체 외곽 | 약 285.781 × 95.334 mm |
| 자석 | Ø3×2, 보스 6개 + 다리 2쌍 4개 = 10개 |
| 다리 자석 포켓 | 커버 Ø3.2 / plate Ø3.3. X 94.0·167.7, Y 2.5 |

r2 DWG의 P4·P5는 각각 윗면이 평평하고, 세 조각의 윤곽은 거의 일치한다. v5도 세 조각의 윗면을 Z 19(참고 키캡 밑면 17.3 + 덮음 1.7)로 평탄화했다. r2와 비교해 v5에는 키캡 여유 1.0 mm를 위한 창 확장과 밑면 자석 체결이 적용된다.

## 체결·분해

PSD60 → mount 4개 → M3 스탠드오프 6개 → plate L/R → 커버 순서다. 좌우 mount에 각각 2곳, 중앙 뒤에 1곳, 중앙 앞에 2곳의 평평한 받침면을 뒀다. 좌측 두 받침은 SO1·SO2 보스 외곽 쪽이 넓어지고, 나머지 받침은 mount 길이 방향을 따라 양끝을 둥글게 마감했다. 타건 하중을 plate 밑면에서 mount로 직접 전달한다. 받침은 스위치와 체결부를 피해서 배치하고 사이를 열어 배선 공간을 확보했다. plate·스위치·배선·컨트롤러는 한 모듈로 들어낼 수 있다. 브래킷은 plate 아랫면에 고정하고 게이트로 Pro Micro 이탈을 막는다.

plate 앞 이음은 dovetail 반턱(상면 쪽 2.4 mm)과 M2×5 나사 1개로 결합한다. tab/포켓 여유는 편측 0.15 mm이므로 이음 쿠폰으로 확인한다. 중앙·뒤쪽은 spine의 M2 나사 4개가 잡는다. spine 배선 홈은 Y 49/64/72, 폭 3 × 높이 2 mm다. 이음의 단차·삐걱임과 접착 필요 여부는 배선 전에 확인한다.

커버 보스는 plate 카운터보어에서 위치를 잡고 자석은 강철 M3 나사머리에 붙는다. 아래 다리의 자석 2쌍은 서로 붙으므로 극성을 맞춘다. 위 다리는 공간이 부족해 자석을 추가하지 않았다. 비용이 큰 plate를 재출력하기 전에 mount·쿠폰 시험, 장공 조정과 상대 부품의 국부 가공으로 맞춤을 확인한다.

## 실측과 가정

[2026-11-04 실측 JSON](../model/measurements/2026-11-04T111846Z.json)은 원본 기록이다. 케이스 폭 286, 깊이 96, 테두리 14는 대략값이며 전체 최솟값으로 확정하지 않는다. H01 지지대 높이 5.5·외경 5와 M08 입력 좌표 성분만 참고 모델에 반영하며 미측정 축은 GH60 후보를 유지한다. mount는 GH60 채택 좌표와 장공으로 시험한다.

케이스 내측 폭 286 기준 외곽 여유는 편측 약 0.11 mm다. 원점 가정을 적용하면 오른쪽에 0.081 mm 중첩이 생긴다. 대략 측정만으로 형상을 축소하지 않으며 실물의 중심 맞춤·접촉을 확인한다.

r2 현물 커버는 체결 상태에서 테두리 위로 최소 3 mm 돌출된다. r2는 5T+2T 아크릴 적층이고 현재 커버는 6T 단일 출력이다. r2 관찰값을 v5 실측 결과로 쓰지 않는다. 맨 아랫줄 키캡 폭은 사용자 확인값 1.25u·1u·2.25u·2u·1u·1u를 따른다. 펌웨어 JSON의 물리 폭 표기는 현물과 다를 수 있어 CAD 폭의 기준으로 쓰지 않는다.
