# 46es split v1 국부 시험 출력안

기준일: 2026-11-05 KST. **계획만 작성. 쿠폰 전용 CAD/STL 생성·출력·발주·제작 승인 없음.**

전체 케이스 jig는 선행 조건이 아니다. 아래 국부 조립 시험과 현물 치수 확인을 독립적으로 진행한다. 전체 부품용 REVIEW_ONLY STL을 쿠폰이라고 취급하지 않는다. 쿠폰을 만들 때 변형 SC의 별도 복사본에서 관심 영역을 남기고,7부품 중 해당 부품만 각각 내보낸다.

## 끼움 비교 쿠폰

- 같은 업체·재료·방향에서 스위치 홀13.9/14.0/14.1/14.2, 국부 체결층1.5T를 비교한다. 기존16.5 릴리프와 실제 회전각을 유지한다.
- M2 통과Ø2.4/2.5, 머리 자리Ø4.4/4.6, 너트 포켓AF4.4/4.5/4.6을 비교한다. 큰 포켓으로 바꿀 때는 주변 최소 살1.2mm 이상을 다시 확인한다.
- M3 지지대 AF5.4/5.5/5.6과 커버 보스/Ø6 자리의 실제 끼움을 비교한다. 후보 변경을 전체 모델에 자동으로 확대 적용하지 않는다.
- 조립 직후와 반복 탈착 후 구멍 크기, 들뜸, 층간 균열, creep, 자석 이탈을 기록한다. 부품을 눌러서 강제로 맞춘 결과는 합격으로 기록하지 않는다.
- 작은 배선/다이오드/납땜은 실제 크기와 경로를 기록해 새 점유 모델에 반영한다.8mm 돌출 수치 하나만으로 키 높이를 올리지 않는다.

## JLC3DP 검토와 출력 방향

FDM·JLC3DP 우선, 재료는 미정이다. ABS/ASA/PLA-P 등은 현재 가능한 공정 후보를 비교하기 위한 이름이며 채택하지 않았다.

업체의 [설계 가이드](https://jlc3dp.com/help/article/3d-printing-design-guideline)는 FDM 공칭 모델 공차±0.3mm(100mm 이내)/±0.4%(그 이상), 홀 공차±0.4mm와 작은 부품 최소 크기30×30×10을 제시한다. 이 조건으로 현재0.15–0.7mm 설계 여유를 보장할 수 없다. 얇은 plate와 작은 gate/spine/bracket의 접수 가능 여부, 후가공, 연결 캐리어/묶음 출력의 허용 여부를 업체에 확인해야 한다. 임의로 영구 형상을 키워 최소 크기를 맞추지 않는다.

예를 들어 [JLC3DP ABS 자료](https://jlc3dp.com/help/article/abs-plastic)는 권장 벽1.6mm/최소1.2mm를 제시한다. Gate 옆 살1.3mm,1.4mm 받침, 스위치1.5T 층은 국부 시험이 필요한 영역이다. 실제 재료의 공차/층간 강도/열변형/표면을 비교하고 최종 재료를 정한다.

Plate는 윗면을 베드 쪽으로 하는 기존 후보를 먼저 검토하되 counterbore와 걸쇠 층의 지지 제거·면 품질을 확인한다. Mount lap은 Z−3~0의 tongue와 상부 rail 단차를 포함한다. 두 출력 방향의 층간 하중을 비교한 뒤 정한다. Bracket/gate의 너트 포켓과1.4mm 받침에는 지지재가 남지 않아야 한다. REVIEW STL의 조립 좌표 배치는 프린트 베드 배치가 아니다.
