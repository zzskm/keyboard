# 46es v4 — 재료·색: plate·mount 검정 MJF, 커버 투명 레진 (2026-11-06)

## 결정

사용자 대화(2026-11-06), 순서대로:

1. "jlc에서 parts 단위로 색상 지정 돼?" → 견적 화면에서 파일마다 재료·색을 따로 고른다(파일 하나 = 주문 줄 하나).
2. "cover는 fdm으로 하고 색상, 표면 다르게 설정했으면 하는데" → FDM은 아래 이유로 맞지 않는다고 답했다.
3. "cover는 black 재료로 적절한거로 선정해줘. 면 품질, 비용 우수한 걸로" → JLC Black Resin을 골랐다(문서 작업 중 바뀜, 커밋 안 됨).
4. **"mount, plate는 black으로 하고 cover는 transparent resin으로 변경해줘"** → 지금 기준.

| 부품 | 재료 | 이전(2026-11-05) |
|---|---|---|
| plate L/R, mount 4개 | **MJF PA12S-HP 나일론, 검정** | MJF PA12-HP 자연 회색 |
| spine, 컨트롤러 브래킷, 게이트 | **MJF PA12S-HP 검정** (plate와 한 묶음이라 같이) | 같음 |

| 보스 탭 | **8001 레진, 투명** (커버 시험물) | MJF PA12-HP 자연 회색 |

모델, 매개변수, 출력 파일(STL/STEP)은 바꾸지 않았다. 견적 화면에서 파일마다 재료를 고른다.

## 왜 이 재료인가 (JLC3DP 업체 페이지, 2026-11-06 확인)

### 검정 MJF: PA12S-HP

- JLC3DP의 [PA12S-HP 페이지](https://jlc3dp.com/help/article/pa12s-hp-nylon)는 색을 "Black; Gray"로 낸다. [PA12-HP](https://jlc3dp.com/help/article/PA12-HP-Nylon)는 자연 회색만 안내한다.
- 규격은 PA12-HP와 같다: 공차 ±0.3 (100 mm 이내) / ±0.4 %, 권장 벽 1.0 초과, 최대 370×276×360, 최소 5×5×5, 열변형 175 °C. 그래서 [MJF 전환](mjf-pa12-2026-11-05.md)에서 고친 형상(모든 벽 1.0 이상)이 그대로 맞는다.
- 업체 블로그 [PA12 vs PA12S](https://jlc3dp.com/jp/blog/pa12-vs-pa12s): 출력 그대로 표면 Ra 6–8 µm(PA12 10–12), 염색이 고르고 로트 간 색 차이가 적고, 구멍·넓은 면의 치수가 더 안정적이다. 대신 파단 연신이 낮다(블로그 6–10 % 대 15–25 %, 업체 페이지 12 % 대 20 %). 눌러 끼우는 맞춤이 빡빡하면 힘으로 넣지 말고 줄로 다듬는다.
- 검정은 회색과 치수가 조금 다를 수 있다. 한 사용자 시험에서 14.1 각형이 회색 14.0, 검정 14.1이었다([Green Keys](https://green-keys.info/en/types-of-3d-prints-that-can-be-ordered-from-jlc3dp-and-their-expansion-rates)). 그래서 plate 시험물(B 쿠폰, 이음 쿠폰)도 같은 검정으로 뽑는다.

### 투명 레진: 8001

[8001 Photosensitive Resin](https://jlc3dp.com/help/article/photosensitive-8001-resin):

| 항목 | 값 |
|---|---|
| 색 | 투명(Transparent): 사포질 + 투명 코팅(oil spraying)이 기본. 반투명(Translucent): 받침만 떼고 사포질 없음 |
| 공차 | ±0.2 (100 mm 이내) / ±0.3 % |
| 권장 벽 | 0.8 초과 |
| 크기 | 최소 5×5×5, 최대 780×780×530 |
| 기계 성질 | 인장 48 MPa, 파단 연신 12 %, 노치 아이조드 28 J/m, 굽힘 탄성률 2,100 MPa, Shore D 86 |
| 열변형 | 53 °C. 실외·고온·강한 햇빛·자외선 환경 비권장 |
| 시작가 | $0.3 |
| 한계(업체) | 표면 기포·작은 구멍을 완전히 없앨 수 없고, 복잡한 형상은 완전히 투명해지기 어렵다 |

커버 STL 3개와 보스 탭을 `inspection/scripts/thin_wall_scan.py`로 다시 쟀다. 가장 얇은 벽은 커버가 보스 둘레 1.09(커버마다 2곳), 보스 탭이 1.30이다. 커버의 나머지 벽은 1.6 이상이다. 권장 벽 0.8을 모두 넘는다. 1.0 미만 값(0.58–0.70)은 창 모서리 끝이고 벽이 아니다.

### 고르지 않은 것

| 후보 | 이유 |
|---|---|
| 커버 FDM (PLA-P 검정·흰·빨강·파랑, ASA 검정·흰) | 최소 크기 30×30×10에 커버 두께 3.5가 걸린다. 보스 둘레 벽 1.09가 FDM 권장 1.6(ASA 최소 1.2)에 못 미친다. 구멍 공차 ±0.4. 층 줄 |
| 커버 JLC Black Resin | 사용자가 투명으로 바꿨다. 형상은 그대로 맞는다(권장 벽 0.8) |
| MJF 검정을 PA12-HP 염색으로 | JLC 페이지에 PA12-HP 검정이 안내되지 않는다. PA12S-HP는 검정을 정식 색으로 내고 염색이 더 고르다 |

## 투명 커버 때문에 바뀌는 것

- **아래가 비쳐 보인다.** 검정 plate 윗면, 커버 T 아래 앞 이음 선과 M2 머리(X 139.5), 보스 속 자석 6개, 그 밑 M3 버튼헤드가 보인다.
  - 위 M3×4는 **흑색 합금강**으로 산다. 자석이 붙어야 하므로 탄소강이어야 하는 조건은 그대로다.
  - 자석은 흑색 에폭시 코팅 Ø3×2가 있으면 그것을 산다. 없으면 보통 니켈 도금도 된다(은색 점 6개가 보인다).
- **자석 접착은 투명 2액형 에폭시.** 순간접착제 증기는 투명 레진 표면을 하얗게 흐린다(백화). 포켓 바닥에 조금만 바른다.
- 받침 자국은 업체 사포질로 지워지지만 비쳐 보이는 부품이다. 주문 메모에 "Top face (flat side without bosses) is cosmetic. Please put supports on the boss side only."를 적는다.
- 투명 레진은 햇빛·자외선에서 누렇게 변할 수 있다(투명 광경화 레진의 일반적 성질, 업체도 자외선 환경 비권장).
- 레진은 나일론보다 덜 늘어난다. 커버를 벗길 때 창 사이 1.6 살을 비틀지 않는다.
- 투명 커버가 뿌옇게 나오거나 깨지면, 형상은 그대로 두고 8001 반투명이나 MJF PA12S-HP로 바꿀 수 있다(커버는 MJF 최소 벽 1.0도 통과).

## 주문 1 시험에 더하는 것

- 보스 탭(투명 레진) + B 쿠폰(검정 MJF) = 실제 커버 + plate 조합. 기존 시험(보스 끼움, 자석 포켓 3.2 / 3.3 / 3.4, 붙는 힘)에 더해 투명도, 기포, 받침 자국, 에폭시로 붙인 자석이 비쳐 보이는 모습을 본다.
- B 쿠폰·이음 쿠폰은 검정 PA12S-HP라 스위치 홀 결과를 검정 plate에 그대로 쓴다.
