# 46es — PSD60 Defender 조립 구조 및 정비성 설계 기준

상태: 설계 제안 / CAD 미반영 / PSD60 현물 미검증 (2026-11-03, 검사 보고서·실측 시트와 연결 2026-11-04)

## 범위와 원칙

- **실제 프로젝트는 46es**: 46키 non-split, 좌우 영역이 나뉘어 있지만 하나의 PSD60 Defender 하우징에 넣는 hand-wired 키보드다.
- **46es_r2_keyboard.dwg**는 기존 리비전의 CAD 자료다. 2D 형상은 [r2 DWG 검사 보고서](../inspection/46es_r2_dwg_inspection.md)에서 읽어 DXF로 내보냈다. 도면에는 기입 치수와 Z(두께·높이) 정보가 없다. MText 재료 표기(아크릴·압출판·아스텔 판재)는 3D 프린팅 리비전이라는 설명과 맞지 않아 확인이 필요하다. DWG 값은 참고값이며 조립 치수는 현물 실측 전까지 미확정이다.
- **46sp는 별도 split keyboard의 참고 예시**다. 46sp의 스위치 개수·키 배치·홀 수는 46es의 검증 기준이 아니다.
- PSD60 Defender는 GH60 호환 하우징이지만 GH60 PCB의 홀 좌표를 하우징의 확정 실측치로 간주하지 않는다.
- 기존 5T 아크릴 구조의 타이핑 형상(행별 위치·높이·각도)을 먼저 복원하고, 프린팅에 맞는 지지·체결 방식을 재설계한다.
- 아래의 실측 ID(M01–M21)는 [`model/measurements.csv`](../model/measurements.csv)를 따른다. 미확정 매개변수(`TBD_`·`CAND_`·`REF_`)와 출력 전 확인 단계(A–G)는 [`model/README.md`](../model/README.md)에 있다.

## 제안하는 기계적 부품 분할

```text
PSD60 Defender (기성 알루미늄 하우징)
  └─ Mount Frame (별도 3D 프린트, GH60 포스트에 고정)
       ├─ Standoff / Plate 지지점 (교체 가능한 체결부)
       │    └─ Switch Plate + hand-wiring (탈착 가능한 1개 모듈)
       ├─ Pro Micro Bracket (교체 가능한 소형 부품)
       └─ USB 연장선 / 내부 케이블 고정
Switch Cover (별도 3D 프린트, Plate 또는 Frame에 독립 체결)
```

이것은 **Tray Mount 하우징에 맞춘 프레임 어댑터**다. 일반적인 Top Mount나 Gasket Mount라고 부르지 않는다. 하우징 자체의 새로운 상판·하판을 만들지 않는다. Plate / Frame / Cover는 초기에는 분리하여 적합성 확인 후 통합 여부를 결정한다.

| 부품 | 반드시 만족할 조건 |
| --- | --- |
| Mount Frame | GH60 후보 좌표로 현물 체결 시험, 포스트 높이·나사 유효 깊이 확인, 배선 공간 개방, 구부림 없이 체결 |
| Plate | 스위치 고정·행별 자세 유지, 5T 구조부와 스냅 체결부 두께 구분, 주변 보강, 상부에서 나사 접근 |
| Standoff | 기존 육각 부품 재사용 가능성 확인, 조립 중 동반 회전 방지, 스위치·납땜부·공구와 간섭 없음 |
| Cover | 키캡을 누른 상태에서도 간섭 없음, Frame을 케이스에서 떼지 않고 분리 가능, 코너 R 현물 시험 |
| MCU Bracket | Pro Micro 단독 교체, USB 삽입·분리 응력 프레임으로 전달, 금속 하우징과 전기 절연 |
| Wiring | Plate 모듈과 MCU 사이 탈착식 커넥터, 커넥터 방향 식별, 고정·장력 완화, 납땜부 절연 |

## 스위치 Plate 및 키캡 간섭

- 스위치 개구부 **14 × 14 mm**는 기존 아크릴 결합의 출발값이지 출력 후 확정 치수가 아니다. r2 DWG에는 14.000 × 13.999로 그려져 있다. 실제 홀 크기는 M11에서 잰다.
- 표준 MX 계열에서 흔히 쓰는 **약 1.5 mm**는 *스위치 걸쇠가 체결되는 국부 두께*의 시작 조건이다. 해당 스위치 모델과 출력 공정으로 실물 시험한다.
- 기존 **5T Plate를 전체 1.5T로 바꿀 필요는 없다**. 5T를 유지하는 영역은 구조 강성을 담당하고, 걸쇠가 위치하는 부분만 하면 포켓 또는 국부 박육 처리를 검토한다. 전체 1.5T Plate는 별도 대안으로 평가한다.
- 참고 사례: r2 DWG의 스위치 판(P2)은 **전체 1.5T 압출판**이고, 다른 판재 5장(2T·5T)과 함께 6층으로 적층된 구조로 그려져 있다([검사 보고서](../inspection/46es_r2_dwg_inspection.md) §4). 적층 순서는 추정이고 두께는 MText 공칭값이다(실두께는 M21).
- 13.9 / 14.0 / 14.1 / 14.2 mm 홀과 걸쇠 하면 포켓을 갖는 소형 샘플로 삽입력·고정력·키캡 제거 시 스위치 이탈을 시험한다(M11·M18·M19, 단계 B).
- **Plate 윗면~키캡 하단 유격은 고정 치수가 아니다.** 사용 스위치·키캡 프로파일·스위치 총 스트로크에 따라 다르다. 키캡 미입력 및 완전 입력 상태에서 최저점을 측정하고 Cover 높이를 결정한다.
- Cover의 각 키 구멍은 스위치 14 mm 홀과 다른 치수다. 키캡 외형·스트로크·기울기·출력 공차를 반영해 설계하며 동일한 14 mm 홀을 복제하지 않는다.

## 하우징 결합과 높이 스택

1. 원점은 **GH60 PCB 앞쪽 왼쪽 기준**의 참조 좌표이며 PSD60 외곽 모서리가 아니다. `planning.md`의 GH60 좌표(모델의 `CAND_H01`…`CAND_H06`)는 시험 후보로만 사용한다. r2 DWG의 체결 후보 6점은 GH60 공개 좌표와 최적 평행이동 후에도 최대 약 1.1 mm 어긋난다(검사 보고서 §4). 어느 쪽도 PSD60 실측값이 아니다.
2. 먼저 얇은 **GH60 포스트 체결 시험 지그**를 출력한다(단계 A). 모든 나사가 억지 없이 들어가고 프레임에 휨이 없는지 확인한다.
3. 하우징의 실제 포스트 상면 Z, 나사 규격·유효 깊이, 외곽 내측 공간, USB 개구 위치를 실측한다(M01–M03, M05, M07–M10, M16).
4. Frame → Standoff → Plate 윗면의 Z 스택을 정한다. 기준은 기존 46es 조립 상태에서 유지할 키 높이·경사다. DWG에는 Z 정보가 없으므로 기존 판별 실두께와 적층 높이는 M21에서 잰다.
5. Plate 아래쪽에는 스위치 핀, 다이오드, 납땜, 행·열 배선, MCU와 USB 플러그, 인서트·나사 돌출을 포함해 실물 기반 간섭 검사를 한다.
6. 금속 하우징과 노출 배선이 접촉하지 않도록 절연·클립·고정점을 마련하고, 흔들었을 때 케이블이 움직이지 않게 한다.

## Pro Micro / USB

- Pro Micro의 정확한 보드 변형, USB 커넥터 종류·방향, 리셋 수단을 확정할 때까지 브래킷 나사홀을 고정하지 않는다.
- 46es 펌웨어 JSON은 **4행 × 12열, 16개 매트릭스 신호선**을 사용한다. 핀 이름은 행 D1·D0·D4·C6, 열 D7·E6·B4·B5·F4·F5·F6·F7·B1·B3·B2·B6으로 ATmega32U4 계열이다(검사 보고서 §5). 일반 Pro Micro 핀 배치라면 16개가 모두 헤더에 있고 D2·D3(RX·TX)가 남는다. 실제 보드 변형의 GPIO·USB·Reset 핀과 대조한다(M15).
- 가능한 경우 Pro Micro는 **Frame에 체결한 독립 Bracket**에 장착한다. Plate와 MCU 사이 행·열 케이블은 착탈식·방향 구분 가능한 커넥터로 연결한다.
- Pro Micro USB 포트에 외부 케이블을 직접 반복 삽입하기보다, 하우징의 기존 USB 구멍에 맞는 **패널 고정형 USB 커넥터 + 짧은 내부 케이블**을 우선 검토한다. PSD60 개구 치수·방향을 실측하기 전 부품 규격은 확정하지 않는다.
- MCU 교체 시 인접 스위치의 납땜을 해제하지 않아도 되어야 한다. 브래킷 체결 나사, USB 연결부, 매트릭스 커넥터에 공구와 손이 들어갈 경로를 확보한다.

## 목표 분해·점검 절차

1. USB 전원을 제거한다.
2. Cover를 독립적으로 제거한다. 필요하면 해당 위치 키캡만 분리한다.
3. **위에서 접근 가능한** Plate↔Frame 나사만 풀고, Plate+스위치+hand-wiring 모듈을 조금 들어 올린다.
4. 매트릭스 커넥터를 분리하여 Plate 모듈을 통째로 꺼낸다.
5. Pro Micro만 점검 또는 교체할 때는 Frame을 하우징에 고정한 채 MCU Bracket을 풀 수 있어야 한다.
6. **GH60 하우징 체결 나사**는 Frame 자체의 교체/수리 때만 푼다.

검증 기준: Cover 탈거만으로 Plate 체결 나사에 접근하는가, Plate를 들어 올리는 동안 배선이 당겨지지 않는가, Pro Micro 교체 시 스위치 납땜을 건드리지 않는가, 재조립 때 육각 스탠드오프가 동반 회전하지 않는가.

## 변경 범위

현재 문서는 설계 기준을 정리한다. **DWG 형상이나 실제 제품 치수의 검증 완료를 의미하지 않는다.** 실측과 샘플 검증 결과를 CAD에 반영한 뒤 최종 출력용 도면을 확정한다.
