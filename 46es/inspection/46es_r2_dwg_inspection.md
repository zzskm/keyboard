# 46es r2 DWG 검사 및 제작 모델 준비 보고

작성일: 2026-11-03 · 대상: `46es/cad/46es_r2_keyboard.dwg` (기존 아크릴 버전 설계 파일, 새 3D 프린팅 케이스의 제작 도면 아님)

> **이 문서와 `46es/model/`의 어떤 값도 제작 확정 치수가 아니다.** DWG 값은 "DWG에 그렇게 그려져 있다"는 사실일 뿐 PSD60 하우징·실부품과 맞는다는 근거가 아니다. 최종 형상·STL은 만들지 않았다.

> 정정 2026-11-04: 46sp는 별도 split keyboard 예시라 대조 대상에서 뺐다(§1, §7). 부품 구성(§5)은 [`docs/assembly-revision.md`](../docs/assembly-revision.md) 기준으로 갱신했다. r2 DWG는 3D 프린팅 리비전이 아니라 아크릴 버전의 설계 파일로 확인됐다(§1). DWG 판독 결과는 바뀌지 않았다.

상태 표기: **확인** = 파일에서 직접 읽은 사실 · **추정** = 근거 있는 해석이지만 미검증 · **미확정/알 수 없음** = 실측 전에는 정할 수 없음 · **자리표시** = 스케치를 그리기 위해 넣은 임시값

## 1. 요약

- DWG는 **열린다.** CADCraft 0.17.0으로 읽었고, 공개 DWG 사양으로 직접 작성한 별도 판독기로 교차 검증했다. **모델 공간의 엔티티 229개는 두 판독 결과가 개수·종류·레이어·원/원호 값까지 완전히 일치**한다.
- 손실은 **형상과 무관한 부분에서만** 확인됐다. 고아 치수 블록 4개, 빈 익명 그룹 1개, 그리기 순서·사전 일부가 DXF 내보내기에서 빠진다(§3).
- 도면에 **기입 치수(DIMENSION)는 0개**다. 모든 치수 후보는 형상에서 산출했다. 엔티티는 전부 레이어 `0`에 있어서, 레이어 이름으로는 부품을 구분할 수 없다.
- **Z(두께·높이) 정보가 없는 순수 2D 도면**이다. 모델 공간 229개 모두 Z = 0, thickness = 0, 돌출 방향 +Z다. 판 두께는 MText 라벨(2T/5T/1.5T/2T/5T/2T, 합 17.5)로만 존재하며 공칭값이다.
- 도면은 **판재 6종(모두 286.4 × 95.8)의 적층 구조**다. MText에는 3D 프린팅 재료가 아닌 판재 재료(투명아크릴, 압출판, 아스텔, 스모그아크릴)가 적혀 있다. 처음에는 r2를 기존 3D 프린팅 리비전으로 설명했으나, 사용자가 **아크릴 버전의 설계 파일**이라고 확인했다(2026-11-04). 판재 재료 표기와 일치한다.
- 스위치 판(1.5T 압출판)에는 **14 mm 개구부가 46개** 있어 펌웨어의 46키와 개수가 맞는다. 그중 1개는 H01 위치의 육각 컷과 겹쳐 윤곽이 합쳐져 있다(W4). 46sp DXF의 45개 집계는 별도 split keyboard 도면의 값이라 46es와 대조하지 않는다.
- r2 체결 후보 6점은 GH60 공개 좌표와 **최대 약 1.1 mm** 어긋난다(최적 평행이동 후). 어느 쪽도 PSD60 실측값이 아니다.
- 실측 전이라 SolidCraft에는 **매개변수 83개와 부품별 2D 초안 스케치 5개만** 만들었다. 미확정 값은 이름에 모두 `TBD_`를 붙였다.

## 4. 형상·레이어·단위·치수 후보

### 단위 (확인)

`$INSUNITS=4` (mm), `MEASUREMENT=1` (미터법), `LUNITS=2` (십진수), `LUPREC=4`. 범위는 (−76.13, 28.46) – (308.37, 779.15)이며, 판 6종이 세로로 펼쳐져 있다. 삭제된 치수 텍스트는 소수 쉼표 표기(ISO-25 스타일)다.

Z 방향: 모델 공간 엔티티 229개 모두 Z = 0, thickness = 0, 돌출 방향 +Z다(확인). 앞뒤 깊이(Y)는 판 외곽 95.8이며, 지워진 치수 `95,8`로도 남아 있다. 이는 r2 판의 깊이이고 PSD60 내부 깊이가 아니다.

| 2 (D4) | SFT_T(Z) | ALT_T(X) | C | V | B | N | M | COMM | DOT | SFT_T(SLSH) | UP | — |
| 3 (C6) | ESC | TAB | LCTL | LGUI | LT(1,SPC) | LT(2,SPC) | RALT | MO(3) | — | LEFT | DOWN | RGHT |

46키, 미사용 위치는 (2,11)과 (3,8)이다. JSON 표시 폭은 1u 43개, 1.25u·1.75u·2u 각 1개이고 회전은 전부 0이다. **JSON 좌표는 표시용일 뿐 물리 배치가 아니다.** DWG의 키는 열마다 회전되어 있다(§4). JSON으로는 어떤 물리 치수도 추정하지 않았다.

### DWG 물리 배치와의 대응 (개수는 확인, 키별 대응은 추정)

| 군집 | DWG P2 개구부 | 펌웨어 키 (추정 대응) |
|---|---|---|
| 왼쪽 주 블록 | 5열 × 3행 = 15 (−3·−3·−6·−9·−11°) | Q–T / A–G / Z–B |
| 왼쪽 바깥 열 | 2 (−3°, 위쪽 1개는 W4) | ESC, TAB |
| 왼쪽 아래 | 3 (−3·−3·−11°) | LCTL, LGUI, LT(1,SPC) |
| 오른쪽 주 블록 | 5열 × 3행 = 15 (+11·+9·+6·+3·+3°) + 6번째 열 2개 (+3°) | Y–P / H–SCLN / N–SLSH + BSPC, QUOT |
| 오른쪽 끝 열 | 2 (0°) | PGUP, PGDN |
| 화살표 역T | 4 (+5°) | UP, LEFT, DOWN, RGHT |
| 오른쪽 엄지 | 3 (+11·+7·+3°) | LT(2,SPC), RALT, MO(3) |
| **합계** | 왼쪽 20 + 오른쪽 26 = **46** | 46 |

1.25u·1.75u·2u 위치도 DWG에서는 모두 단일 14 mm 개구부이고 스태빌라이저 컷아웃이 없다. 실제 키캡 폭은 M17에서 확인한다.

### 부품 구성 (신규 계획 기준, `docs/assembly-revision.md`)

```text
PSD60 Defender ─ 하부 마운트 프레임(케이스 체결) ─ 육각 스탠드오프 ─ 스위치 plate(5T 구조부 + 국부 약 1.5T 걸쇠 체결) ─ 별도 체결 cover
                 └ Pro Micro 브래킷(프레임에 체결) · 패널 고정 USB + 내부 케이블 · plate↔MCU 착탈식 커넥터
```

| 부품 | 역할 | 초안 스케치 | 미확정 핵심 |
|---|---|---|---|
| 하부 프레임 | 케이스 체결(GH60 후보 좌표), plate 지지, 배선·컨트롤러 회피 | `SK10_FRAME_DRAFT_TBD` | 외곽(M01–M03), 체결 좌표·나사(M07–M10), 두께·리브 |
| 육각 스탠드오프 | 프레임–plate 연결·높이 | SK10·SK20의 스택 위치 원 | 형식·AF·길이(M13), 높이(M05·M14) |
| 스위치 plate | 스위치 위치·높이·고정 | `SK20_PLATE_DRAFT_TBD` + 참고 `SK21_REF_r2_P2_DWG_NOT_FOR_PRODUCTION` | 홀(M11·M18·M19), 간격·각도(M12), 코너 |
| 커버 | 측면 틈·빈 공간 가림 | `SK30_COVER_DRAFT_TBD` | 코너 R 샘플, 높이, 키캡 간섭(M17) |
| MCU 브래킷·USB | Pro Micro 단독 교체, USB 삽입 응력을 프레임으로 전달, 하우징과 절연 | 없음 (SK00에 점유 영역만) | 보드 변형·커넥터(M15), USB 개구부·플러그(M16) |
| (공통) | 하우징 내측 기준, USB·컨트롤러 점유 영역 | `SK00_CASE_ENVELOPE_TBD` | M01–M07, M15, M16 |

r2와 신규 계획은 구조가 다르다. r2는 판재 6층 적층이고 스위치 판이 전체 1.5T다. 신규는 5T 구조부에 걸쇠 체결부만 국부 약 1.5T로 두는 plate를 우선 시험한다(전체 1.5T는 대안). r2에서 이어받을 수 있는 건 **배치(키 위치·각도)와 스택 위치 후보**뿐이며, 이것도 현물 대조(M12·M20) 전에는 참고값이다.

## 7. 다음 측정 작업 (우선순위 순)

전체 시트는 `../model/measurements.csv`에 있다(측정값 칸은 비어 있음).

1. **하우징 내부 기본 치수**: M01 폭, M02 깊이, M03 코너 R, M05 높이, M06 벽. r2 판이 있으면 끼운 상태에서 네 변과 네 코너의 틈을 필러 게이지로 재면 간접 확인이 빠르다. 같은 자리에서 **M21**(r2 판별 실두께, 적층 순서, 전체 높이)도 잰다. DWG에는 Z 정보가 전혀 없다.
2. **체결**: M07 기준점 오프셋, M08 6점 중심 좌표와 중심 간 거리(얇은 GH60 시험 프레임), M09 나사 규격·유효 깊이, M10 지지대 외경·높이.
3. **스위치**: M19 모델과 걸쇠 위치, M11 기존 아크릴 14 mm 홀의 실제 크기, M12 현물 키 간격·각도, M20 키 수·위치 대조(r2 46 / 현물).
4. **하부 공간**: M13 기존 육각 부품, M14 배선 높이, M15 컨트롤러 외형·위치·커넥터, M16 USB 개구부·케이블 플러그.
5. **외관·공정**: M17 키캡·커버 간섭, M04 외형 문서값 검증, M18 출력 조건 확정 후 홀·여유 샘플.

측정값을 `measurements.csv`에 채운 뒤 `parameters.csv`의 해당 `TBD_` 값을 바꾸고, 근거가 생긴 값은 이름에서 `TBD_`를 떼고 주석에 측정 ID와 날짜를 남긴다. 그다음에 솔리드와 시험 출력용 STL로 넘어간다.
