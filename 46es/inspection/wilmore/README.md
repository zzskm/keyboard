# The_Wilmore.stl 검사 — PSD60 실측 전 하우징 대용값

> **Wilmore는 PSD60 Defender가 아니다.** 둘 다 GH60 호환 60% 하우징이라 내부가 비슷할 것으로 보고, PSD60을 실측하기 전까지 대용값으로만 쓴다. 여기서 뽑은 값은 모두 `REF_WIL_` 매개변수에 넣었고, 하우징 관련 `TBD_` 매개변수가 그 값을 참조한다. 실측값이 나오면 `TBD_` 매개변수의 식을 실측값으로 바꾸면 모델 전체가 따라간다(`../../model/README.md` 참고).

검사일 2026-11-04. 원본 메시 파일은 저장소에 넣지 않았다(외부 모델, 재배포 권한 미확인).

## 좌표 변환

1. **경사 제거**: 시트 윗면 법선의 경사 4.633°(케이스 본체·링 윗면도 4.633°)만큼 X축으로 돌려 PCB면을 수평으로 만든다.
2. **비틀림 보정**: 내벽 4면을 직선 맞춤해 나온 Z축 비틀림 0.0164°를 보정한다.
3. **원점**: H03·H04 구멍 중심에 GH60 좌표를 맞춘 점(Wilmore 좌표 305.004, 1.441, 두 구멍 잔차 ≤ 0.001)을 원점으로, 스탠드오프 상면(8.730)을 Z = 0으로 잡는다. 46es 모델의 좌표계(GH60 PCB 기준점, Z = 지지대 상면)와 같다.

## SolidCraft 하우징 대용 바디

`../../model/46es_draft_sketches.sc`의 `REF_HOUSING_WILMORE_NOT_PSD60` 바디. 제작용 아님, 간섭 확인용.

| 피처 | 내용 | 따르는 매개변수 |
|---|---|---|
| `SK40_HOUSING_PROFILE_REF_WILMORE` → `HOUSING_OUTER_REF_WIL` | 측면 단면 5점 폴리곤을 X로 돌출 | `REF_WIL_out_*`, `bot_*`, `chamfer_*`, `TBD_support_to_rim_F/B` |
| `HOUSING_CAVITY_TBD` | 기존 SK00 내측 외곽을 바닥(−`TBD_support_H`)부터 위로 관통 절단 | `TBD_case_in_W/D/R`, `TBD_pcb0_dx/dy`, `TBD_support_H` |
| `SK41_HOUSING_POSTS_CAND` → `HOUSING_POSTS_CAND` | 기둥 6개. H01–H04는 원기둥, H05·H06은 벽까지 이어진 슬롯 모양 보스. 구멍 지름 `TBD_case_screw_D` | `CAND_H0x_X/Y`, `TBD_case_post_D`, `TBD_case_screw_D`, `TBD_support_H` |
| `HOUSING_USB_CUT_TBD` | 뒷벽 직사각형 관통 | `TBD_usb_X/W/H/Z` |

검증:

- 부피 297,430.3 mm³. 손으로 계산한 값 297,430.3과 같다. Wilmore 케이스와 링을 합친 부피는 295,785 mm³(+0.56%, 바닥 모깎기·턱 생략분).
- 기둥 6개의 원통면 중심·반지름이 `CAND_` 좌표, Ø5.0 / Ø2.0과 일치한다(불리언 보정 이동 ≤ 0.0007).
- 바디를 STL로 내보내 Wilmore 메시와 Z = −5.5 / −3 / −0.3 / 4 / 10 단면을 겹쳐 비교했다. 내벽은 0.01 이내, 외곽은 0.15 이내(외벽 구배 생략분), USB 개구부와 앞 경사면은 일치한다. `render/compare_*.png`(파랑 = SolidCraft, 주황 = Wilmore)
- 스케치 7개 모두 자유도 0, 타임라인 오류 0.

Wilmore와 일부러 다르게 만든 부분: 케이스와 링을 한 덩어리로 만들었고, 바닥 시트를 빼고 기둥을 바닥에서 세웠다(Wilmore 스탠드오프는 바닥 위 1.53에서 시작). 기둥 좌표는 GH60 값을 썼고, 내부 바닥·벽 모서리의 약 1 mm 모깎기, 외벽 구배, 바깥 모서리 형상, 쐐기(성분 6)는 생략했다.

## 재현

스크립트는 `scripts/`에 있다. numpy와 scipy만 쓴다. 임시 폴더에서 실행했으므로 경로는 바꿔서 쓴다.

```bash
python -I scripts/stl_overview.py The_Wilmore.stl wilmore.npz       # 개요·성분
python -I scripts/components.py wilmore.npz wil_lab.npy             # 성분 라벨
python -I scripts/untilt.py wilmore.npz wil_lab.npy wil_kb.npz      # 경사 4.633° 제거
python -I scripts/frame2.py wil_kb.npz wil_lab.npy wil_kb2.npz      # 비틀림 0.0164° 보정
python -I scripts/crossings.py wil_kb2.npz wil_lab.npy 2 12         # 링 내·외면 위치
python -I scripts/corners.py wil_kb2.npz wil_lab.npy 2 12 304.311 590.692 0.774 96.708 2.9   # 링 내측 R
python -I scripts/loops2.py wil_kb2.npz wil_lab.npy 0,1,2,3,4,5 6   # 구멍 중심
python -I scripts/vcross.py wil_kb2.npz wil_lab.npy 450 sec.npz     # 높이(바닥·시트·테두리)
python -I scripts/ysec.py wil_kb2.npz wil_lab.npy 0 101.5 318.5,323.7 3.7,10.8 310 340       # USB
python -I scripts/compare.py wil_kb2.npz wil_lab.npy housing.stl cmp # 대용 바디와 단면 비교
```
