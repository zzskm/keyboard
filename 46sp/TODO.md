# 46sp 남은 작업

작성일 2026-11-11. 설계 기준은 [README](README.md)다. 기존 케이스·플레이트·키스위치 조립 완료와 3D 프린팅 전환 의도를 반영했다. 체크박스는 해당 작업의 완료 기준을 확인하고 결과를 저장한 뒤 표시한다.

## 현재 상태와 채택한 방향

- [x] 기존 합판 케이스·아크릴 플레이트·키스위치 조립 완료. 사용자 확인 사항이다.
- 내부 구조 미설계의 한계를 해결하기 위해 3D 프린팅으로 전환한다. 출력용 케이스·플레이트·내부 지지·체결 구조를 SolidCraft에서 함께 설계하고, 기존 조립체를 키 배열과 형상의 기준으로 활용한다. 기존 스위치의 이식 가능 상태도 확인한다.
- 46키(46es와 같은 물리 배열)를 기준으로 진행한다(2026-11-12). r3 판(45개)과의 차이는 왼쪽 3행 바깥 키를 빼고 오른쪽 1·2행에 한 키씩 더하는 것이다. 오른쪽 폭은 사용자가 실물 케이스를 보고 다시 검토한다. [README 키 배열](README.md#키-배열-46키)
- r3 플레이트 9개와 내부 지지 부품 15개의 SolidCraft 복원 및 솔리드·부피 검증을 마쳤다. 현재 모델의 배치는 가공 전개도 좌표다.
- 짧은 리브 2723용 받침, Pro Micro 받침, 스위치 끼움 시험편의 SolidCraft 시제품이 있다. 2723 리브와 받침의 명목 치수상 겹침은 0 mm³로 확인했다. 리브 받침은 기존 합판·아크릴 활용을 전제로 만든 초기 시제품이다. 출력용 전체 조립 설계는 남아 있다.
- 컨트롤러는 보유 USB-C ATmega32U4 Pro Micro 두 개다(사용자 정정 2026-11-12, RP2040-Zero 전환을 되돌림). PC는 왼쪽 USB-C로 연결하고, 좌우는 GND·5 V·D2의 3선 시리얼로 연결한다. 반쪽마다 4행 × 7열 `COL2ROW`로 배선한다.
- 출력 모델 [46sp-print.sc](model/46sp-print.sc)이 있다(2026-11-12, [README 출력 모델](README.md#출력-모델-mjf)). MJF 외주 출력, 좌우 연결은 보유 AUX. 반쪽마다 굽은 plate(인서트 다리 6개)와 트레이 case, 바닥에서 M3×10으로 체결한다. 전체 기울기 0°와 plate 밑면 최저 Z 10은 가정이다.
- 46sp 전용 QMK 설정이 있다. 키맵은 46es의 네 레이어를 물리 위치대로 옮긴 46키이며, 46es와 키별로 대조했다. 45키 판은 QMK `d194c077ed`에서 ATmega32U4와 RP2040으로 빌드한 적이 있으나 46키 판은 아직 컴파일하지 않았다. 실제 보드의 플래시·입력 시험은 남아 있다.

## 진행 순서

기존 조립체 기록과 출력 조건 확인 → 스위치·체결 시험편 → 출력용 케이스·플레이트·내부 구조 설계 → 커넥터와 배선 경로 확정 → 한 행·한쪽·양쪽 순서로 출력 및 이식·배선 → 펌웨어 실기 시험 → 최종 조립 검증 순으로 진행한다. 부품 실물 규격 확인과 펌웨어 빌드·플래시 절차 정리는 기구 설계와 함께 진행할 수 있다.

## 1. 기존 조립체 기록과 출력 조건 확인

- [x] 키 수 차이를 원본 DWG로 확인했다. r3 판 45개, 조립도 44개이며 "46키"는 46es 키맵의 배선 행에서 온 숫자였다. 46키로 진행하기로 하고 QMK 레이아웃과 모든 레이어를 46키로 맞췄다(2026-11-12).
- [x] **키 배열 확정 (46키)**: 왼쪽 L_R0=6, L_R1=6, L_R2=5(6→5), L_R3=3 → 20키. 오른쪽 R_R0=7(6→7), R_R1=7(6→7), R_R2=5, R_R3=3, R_Thumb=4 → 26키(사용자 2026-11-12).
- [x] case 폭은 그대로 두고 plate를 고쳤다(2026-11-13): [46sp_plate_46key.dxf](source/46sp_plate_46key.dxf), 생성·검사 [tools/plate_46key.py](tools/plate_46key.py). 오른쪽 6·7번은 19.05 간격 X 280.775·299.825. README [46키 plate](README.md#46키-plate-기존-case-재사용).
- [x] 리브는 쓰지 않는다(사용자 2026-11-13). 새 plate는 반쪽마다 한 덩어리로 출력한다.
- [x] case는 CNC 적층 합판이고 측벽은 끼움 결합이다. 작업이 끝나면 목공풀로 고정한다(사용자 2026-11-13). 그래서 기존 아크릴 측판을 쓴다. 출력 plate 끝 4 mm를 r3 단면(두께 5.0, 홈 5.5)으로 만든다.
- [x] 출력 plate와 bottom cover를 설계했다(2026-11-13, [tools/build_plate_cover.py](tools/build_plate_cover.py)). 로고 `kb46sp/26`(46es와 같은 Xifiction 폰트)를 오른쪽 3행 높이 ↑ 키 바깥쪽에 음각했다(높이 2.5). cover는 목재 나사 6개로 고정한다. 바닥 홈 세 줄은 bone 막대 자리라 피했다.
- [x] 실물 아크릴은 r3 DWG 라벨대로 plate·측판 5T(검정아스텔), 리브 1.5T(투명압출판)다. 측판 홈은 DWG의 5.5이고 출력 plate가 이를 따른다. STEP(f3d) 측판은 이전 설계다(사용자 확인 2026-11-13).
- [x] 오른쪽 case는 왼쪽과 같은 구조이고 조금 넓다. AUX 구멍은 왼쪽 면에 있고 USB 출구는 없다(사용자 2026-11-13). 오른쪽 cover는 안쪽 폭 158(r3 판·bone 막대)이고, 뒤 계단은 USB 출구가 있는 왼쪽에만 둔다.
- [x] 뒤 블록에는 단차가 없다. STEP의 왼쪽 뒤 블록 안쪽 절반(`inside_bw_b`)은 다른 버전 형상이다(사용자 2026-11-13). 조립체와 cover에서 단차를 없앴다.
- [ ] 컨트롤러 고정 위치와 고무발 자리를 cover·case에 정한다.
- [ ] 지금 조립된 키보드에 키캡을 끼우고 엄지 행(왼쪽 LCtl·LGui·Spc, 오른쪽 Spc·RAlt·FN)과 오른쪽 ←↓→를 끝까지 눌러, 키캡 앞 아래 모서리가 앞 블록 안쪽 윗모서리에 스치는지 본다([그림](images/check-thumb-keycap.png)). 키 위치는 아크릴 판과 같다. 조립체 모델에서는 0.4 mm(오른쪽 ↓는 1.8 mm) 겹친다.
- [x] 측벽의 측판 자리 깊이는 재지 않아도 된다. 출력 plate는 지금 끼워진 아크릴 plate와 길이·끝 모양이 같아서, 지금 들어가 있으면 그대로 들어간다. STEP의 4 mm 자리는 옛 측판용 모델 값일 뿐이다.
- [x] 조립 가이드를 실물 case·출력 plate 기준으로 새로 썼다([ASSEMBLY.md](ASSEMBLY.md), 그림은 [tools/build_assembly.py](tools/build_assembly.py), 2026-11-13).
- [ ] MJF 공차에서 plate 끝 혀(5.0)와 측판 홈(5.5)의 끼움을 첫 출력에서 확인한다.
- [ ] 키 중심, 행별 높이·각도, 좌우 외형과 바닥 기준을 기록한다. 특히 책상에 대한 전체 기울기와 앞·뒤 끝 높이를 잰다(STEP에서 측판은 r3 도면 방향에서 13° 돌아가 놓여 있다). 사진이나 도면에 기준면과 측정 위치를 표시한다.
- [ ] 기존 내부 구조에서 해결하지 못한 지지·체결·배선 공간을 기록하고 출력 설계에 반영할 요구사항을 정리한다.
- [ ] 장착된 스위치의 모델·걸쇠 치수·분리 가능 상태와 키캡 규격을 확인한다. 기존 배선 유무도 확인하고 이식할 부품을 정한다.
- [x] 출력 방식: 외주 MJF(검정), 반쪽마다 plate·case 한 부품씩(사용자 결정 2026-11-12). 출력 방향은 STL 내보낼 때 정한다.
- [ ] 스위치 하단·다이오드·납땜·배선과 바닥 사이에 필요한 공간을 실제 부품으로 확인한다.

**완료 기준** — 기존 조립체의 형상·배열·이식 부품과 해결할 내부 구조 문제가 기록되어 있고, 출력 조건이 정해져 있다. 조립체의 미확인 치수와 프린터 조건은 실측·확인이 필요하다.

## 2. 출력용 케이스·플레이트·내부 구조 설계

- [x] r3 측판 홈과 판 구멍에서 좌우 키 중심·행별 기울기를 조립 좌표로 옮겼다(`tools/build_print.py`). 십자 판은 3·4행 면에 놓았다.
- [ ] 스위치 개구와 걸쇠 지지부 시험편을 출력해 끼움 여유를 결정한다. [기존 시험편](model/switch-fit.sc)을 출발점으로 삼고 실제 출력 조건에서 확인한다.
- [ ] 출력 플레이트의 두께, 개구 주변 벽, 보강부와 모듈 분할을 설계한다. 스위치 고정, 키캡 간섭과 누를 때 처짐을 한 행 출력으로 확인한다.
- [x] 케이스 외벽·바닥과 plate 다리를 설계했다. plate는 벽 윗면 전체와 다리 6개로 받친다. 1–3행 안쪽 끝은 다리가 들어가지 않아 벽만 받친다.
- [ ] 좌우 Pro Micro 장착부: 출력 모델에는 RP2040-Zero 치수(23.5 × 18)의 받침이 남아 있다. 기존 case 재사용 방향으로 다시 설계한다. 실물 보드·USB 플러그·납땜 돌출로 확인하고 고정 방식(테이프 또는 걸림)을 정한다. [기존 받침](model/pro-micro-carrier.sc)의 고정 방식을 참고해 실제 보드, 납땜 돌출, USB 플러그와의 간격을 확인한다.
- [ ] 출력 방향, 서포트 제거 접근, 출력 범위에 따른 분할과 접합부를 검토한다. 플레이트를 꺼내는 방향과 하네스 분리 위치도 조립 모델에 반영한다.

**완료 기준** — 출력용 좌우 케이스·플레이트·내부 지지대의 조립 모델이 있고, 부품별 출력 방향과 분할이 결정되어 있다. 솔리드·간섭 검토 결과와 한 행 출력 시험 결과를 저장한다.

## 3. 체결 방식 상세 설계

- [x] 체결: plate 다리 끝 인서트에 바닥 밑에서 M3×10(바닥 패드 카운터보어 Ø6.4 × 2). 반쪽 6곳.
- [x] 보유 원형 황동 인서트 Ø5 × 4(구멍 Ø4.2, 46es B 쿠폰 결과를 따름)와 보유 흑색 M3×10. 12개 사용. 보스 주변 벽 두께와 스위치·배선 간섭을 함께 검토한다.
- [ ] 체결부 시험편을 출력해 조임·풀림, 균열, 인서트 또는 너트의 고정 상태를 확인하고 치수를 반영한다 다리 벽은 Ø7.5 − Ø4.2로 1.65 mm다.
- [ ] USB 삽입·분리 힘을 받을 패널 연장선과 케이블 고정부를 배치한다. 보드 고정과 케이블 고정이 실제 조작 중 유지되는지 확인한다.
- [ ] 배선한 플레이트 모듈과 바닥을 분해·재조립해 패스너 접근과 정비 동선을 확인한다.

**완료 기준** — 출력 부품의 체결 형상, 위치, 패스너 규격·길이·수량이 확정되고, 시험 조립에서 들뜸·흔들림·부품 손상 없이 분해와 재조립이 가능하다.

## 4. 좌우 커넥터와 배선 도면 확정

- [ ] 좌우 커넥터는 보유 AUX 3.5 mm 잭(사용자 결정 2026-11-12). case 안쪽 벽에 Ø6.2 구멍을 냈다. 실물 잭의 나사 지름·몸체 길이·패널 두께를 재서 구멍과 위치를 맞춘다.
- [ ] README의 논리 핀 1=GND, 2=5 V, 3=D2를 실물 커넥터 번호와 대응시킨다. 결합면과 배선면의 보는 방향을 명시한 도면을 만든다.
- [ ] 각 스위치의 물리 위치, 도면 식별자, 로컬 행·열, QMK 행·열, 기본 키를 연결한 배선표를 만든다. 오른쪽 로컬 R0–R3은 QMK 행 4–7이며, 오른쪽 크로스의 순서는 왼쪽·위·아래·오른쪽이다.
- [ ] 사용할 다이오드와 배선재를 정하고, 행·열 버스, 출력 지지대 사이의 배선 경로, 절연 방법, 케이블 고정 위치와 정비용 여유 길이를 정한다.
- [ ] 왼쪽 USB-C의 평소 접근과 양쪽 USB-C·RST 핀의 정비 접근을 확보한다. 좌우 하네스를 분리해 양쪽 보드를 개별 플래시할 수 있는지 확인한다.
- [ ] 전체 부품표에 확정한 키 수만큼의 스위치와 키별 다이오드, Pro Micro 2개와 출력 부품·패스너·커넥터·배선재의 확정 규격 및 수량을 정리한다. 기존 부품의 이식 수량과 추가 확보 수량을 표시한다.

**완료 기준** — 실물 커넥터 방향까지 포함한 연결도, 확정된 전체 키 배선표, 부품표로 좌우 배선을 재현할 수 있다.

## 5. 시제품 제작과 전기 검증

- [ ] 한쪽 케이스·플레이트·내부 지지 부품을 출력하고 기존 스위치를 시험 이식한다. 수축·뒤틀림·끼움·체결·배선 공간을 확인해 모델을 수정한 뒤 양쪽을 제작한다.
- [ ] 다이오드 띠가 행을 향하도록 스위치를 배선하고, 각 스위치에서 보드 핀까지 배선표와 대조한다.
- [ ] 전원을 연결하기 전에 VCC–GND 단락 여부, 케이블 핀별 연속성, 다이오드 방향을 확인한다. 결과와 배선 사진을 저장한다.
- [ ] 왼쪽 단독으로 시작해 전원과 입력을 확인한다. 전원을 분리한 뒤 오른쪽을 연결하고 우측 전원과 통신을 확인한다.

**완료 기준** — 배선표와 실물 연결이 일치하고, 양쪽 보드가 예정한 전원·통신 구성으로 동작한다. 좌우 케이블 탈착과 개별 USB 플래시는 전원 및 좌우 연결을 분리한 상태에서 진행한다.

## 6. 펌웨어 플래시와 키맵 실기 검증

- [ ] [QMK 소스](firmware/46sp/)를 사용할 QMK 체크아웃에서 빌드하고, 전체 커밋 ID·명령·도구 버전을 기록한다. 플래시할 파일과 해당 소스 리비전을 대응시킨다.
- [ ] 실제 Pro Micro의 RST–GND 리셋과 Caterina 부트로더로 플래시 절차를 확인한다. 좌우 케이블을 분리한 상태에서 같은 빌드를 양쪽 보드에 각각 기록한다.
- [ ] 왼쪽 USB 연결에서 좌우 역할과 행 번호가 맞는지 확인한다. 역할 판별이 예상과 다르면 QMK 설정을 수정하고 재시험한다.
- [ ] 확정된 좌우 키를 모두 단독 입력해 위치·키 코드·누름·해제를 확인한다. 뒤집힌 열 순서, 누락, 중복을 기록하고 수정한다.
- [ ] BASE·NUM·SYM·NAV 레이어, 레이어 전환 키, Enter·Backspace·Space, mod-tap·layer-tap의 탭과 홀드를 실제 타이핑으로 확인한다. 필요한 키맵과 타이밍 변경을 반영한다.
- [ ] 양손 동시 입력, 수정키 조합, 키를 누른 채 레이어 변경, USB 재연결 후 복구를 시험하고 붙은 키나 유령 입력이 없는지 확인한다.
- [ ] 수정이 있으면 다시 컴파일·플래시하고 관련 입력 시험을 반복한다. 최종 키맵과 플래시 절차를 문서에 반영한다.

**완료 기준** — 확정된 전체 키와 모든 레이어가 의도대로 동작하고, 좌우 통신·동시 입력·재연결 시험 결과가 기록되어 있다. 기존 컴파일 성공 기록에 실기 시험 결과를 추가한다.

## 7. 최종 조립과 제작 자료 정리

- [ ] 케이스를 닫은 상태에서 모든 키의 전체 스트로크, 키캡 간섭, 배선 눌림, USB·좌우 커넥터 접근을 확인한다.
- [ ] 실제 타이핑과 케이블 조작 중 처짐·들뜸·흔들림을 점검하고, 플레이트 모듈을 한 번 분리·재조립한 뒤 입력을 다시 확인한다.
- [ ] 확정된 SolidCraft 원본과 출력용 STL 또는 3MF에 리비전·재료·수량을 기록한다. 프린터·노즐·레이어 높이·벽 수·인필·출력 방향·서포트 조건과 조립 좌표를 함께 남긴다.
- [ ] 실측 기록, 조립 사진, 부품표, 배선도, 조립·플래시 순서와 시험 결과를 README에서 찾을 수 있게 연결한다.
- [ ] 실제 제작에 사용한 설계·펌웨어 리비전을 기록하고, 수정 파일을 검토한 뒤 커밋·푸시 및 main 반영을 마친다.

**프로젝트 완료 기준** — 3D 프린팅 케이스·플레이트·내부 지지·체결 구조로 전환한 좌우 키보드가 확정된 전체 키와 전체 레이어로 동작하고, 같은 자료로 출력·조립·배선·플래시·정비를 재현할 수 있다.
